# MobileBERT를 이용한 스팸/정상 이메일 분류 분석

---
## 문제 인식
요즘은 거의 모든 사람들이 이메일을 사용하고 있고, 하루에도 수십 통에서 많게는 수백 통의 메일을 받는 경우가 많다. 이 중에는 중요한 업무 메일이나 금융 정보, 지인들의 메시지처럼 꼭 확인해야 할 내용도 있지만, 동시에 광고성 메일이나 피싱, 스팸처럼 원하지 않는 메시지도 굉장히 많다.
이런 불필요한 이메일들은 단순히 귀찮은 수준을 넘어서, 사용자의 집중력을 흐트러뜨리거나 중요한 정보를 놓치게 만들 수 있다. 특히 요즘처럼 스마트폰이나 태블릿 같은 모바일 기기로 메일을 주로 확인하는 환경에서는 스팸/피싱 메일이 주는 보안 위협이 더 크고, 실제 피해 사례도 계속 늘어나고 있는 실정이다.

## 문제의 심각성
스팸 이메일은 단순한 불편함을 넘어서 여러 가지 심각한 문제를 일으킬 수 있다. 대표적으로 피싱 메일은 수신자의 개인정보를 탈취하거나 금융사기로 이어지는 경우가 많아, 보안에 큰 위협이 된다.
또한 기업 입장에서는, 업무용 메일함에 스팸이 쌓이게 되면 중요한 업무 지시나 고객 응답을 놓칠 수 있어서 생산성에도 영향을 준다. 그리고 이런 메일을 계속 받게 되면 사용자 입장에서는 메일을 확인하는 것 자체가 스트레스가 되고, 점점 피로감을 느끼게 된다. 이른바 **디지털 피로감(Digital Fatigue)** 이라고 불리는 현상이다.

결국 스팸 필터링은 단순히 귀찮은 메일을 걸러주는 기능이 아니라, 사용자의 정보 보호와 효율적인 커뮤니케이션을 위한 필수 요소라고 할 수 있다. 개인이든 기업이든, 이제는 더 정교하고 똑똑한 필터링 시스템이 필요한 시점이다.

### [2025년 스팸 메일 동향](#reference)
2025년 기준, 스팸 메일은 다양한 유형으로 나타나며, 그 비율은 다음과 같다.

| 스팸 유형             | 비율    | 설명                                                                 |
|----------------------|---------|----------------------------------------------------------------------|
| 피싱 (Phishing)       | 48%     | 로그인 페이지를 모방하여 사용자 정보를 탈취하는 시도                              |
| 가짜 페이지 메일       | 50%     | 유명 사이트를 위장한 첨부파일 형태의 피싱 메일                                     |
| 배송/물류 관련 메일     | 20.6%   | 배송, 운송, 세관 등을 사칭하여 사용자의 클릭을 유도하는 메일                           |
| 공지/알림성 키워드 메일 | 8.7%    | "긴급", "안내" 등의 키워드로 불안감을 자극하여 클릭을 유도하는 메일                      |

### 스팸 메일 분류 체계
이러한 다양한 스팸 메일은 세부적으로 다음과 같이 분류할 수 있다.

| 분류 | 설명 |
|:-----|:-----|
| 사적 | 개인적으로 또는 업무용으로 주고받은 메일 |
| 사적(초대) | SNS에서 개인 계정으로 보내는 광고·알림 메시지 (초대 등) |
| 정상 광고 메일(수신 동의) | 수신자가 수신을 동의한 광고메일 |
| 정상 광고 메일(기존 거래 관계) | 최근 6개월 이내에 재화를 구매하거나 서비스를 이용한 기존 거래 관계에 기반한 광고메일 |
| 스팸(도박) | 국내외 도박사이트 또는 오프라인 도박 장소를 광고하는 메일 |
| 스팸(불법대출) | 불법 대출 상품 광고 (신용대출, 주택담보대출, 정부지원 사칭 등) |
| 스팸(의약품) | 불법 의약품(비아그라, 시알리스 등) 광고 (건강보조식품 제외) |
| 스팸(주식) | 리딩방, 증권사, 투자 컨설팅사 등에서 발송한 주식 관련 정보 광고 |
| 스팸(카드/보험/은행 등) | 신용카드사, 은행, 보험사에서 보낸 상품 및 서비스 광고 (대출상품 제외) |
| 스팸(재테크/투자) | 코인, 금융 등 재테크 투자 관련 광고 |
| 스팸(성인) | 성인 관련 음란 표현, 유흥주점, 성매매 알선 광고 |
| 스팸(교육/유학) | 자격증 취득, 학위취득, 교재 판매, 유학 관련 광고 |
| 스팸(건강정보) | 건강정보, 건강보조식품 관련 광고 (불법 의약품 제외) |
| 스팸(취업/창업) | 취업, 창업 관련 안내, 홍보, 권유 메일 |
| 스팸(통신가입) | 인터넷 서비스, 휴대전화 가입, 번호 이동 권유 광고 |
| 스팸(기타) | 기존 분류에 포함되지 않지만 수신자를 기만하거나 사회적 물의를 일으키는 메일 |

## 문제 해결 접근
스팸 메일의 유형이 점점 다양해지고 있는 만큼, 이를 효과적으로 식별하고 자동으로 분류할 수 있는 시스템의 필요성이 더욱 커지고 있다. 특히 수작업으로 분류하기 어려운 대량의 메일 환경에서는, 인공지능 기반의 자동 분류 모델이 도움이 될 수 있기 때문에 경량화 된 언어 모델인 MobileBERT를 활용해 이메일 분류 모델을 구현하고, 스팸 메일의 주제를 파악하는 토픽 분석을 통해 스팸 유형을 보다 구체적으로 이해하고자 한다.

### Dataset 설명 (spam_emails_data.csv)
- **kaggle에 있는 문장 분류를 위한 메일 Ham/Spam Dataset**
- 이메일 문장인 `text` 와 정답인 `label`로 구성되어 있다.
- 행은 총 **193,849건**
- 특정 이메일 문장이 너무 길어 엑셀이나 pandas로 열었을때 문자 깨짐이 발생하는 문제점이 있다.

| label | text 예시 (요약) |
|-------|------------------|
| Spam  | `viiiiiiagraaaa...` |
| Ham   | `got ice thought look az original message...` |
| Spam  | `start increasing your odds of success...` |
| Ham   | `attached is the weekly deal report...` |

### 전체적인 데이터 전처리 과정
| 단계 | 내용                                                     |
|------|--------------------------------------------------------|
| 1. 필터링 | 데이터를 로드한 후, `label` 값(0=정상, 1=스팸)에 따라 데이터를 분리한다        |
| 2. 데이터 클리닝 및 정규화 | 텍스트 길이 제한, 언어 필터링, 중복 행 제거. `label` 값은 0과 1로 정규화를 진행한다 |
| 3. 샘플링 | 각 `label` 별 데이터 수를 확인하고, 그에 맞게 알맞은 비율로 데이터를 샘플링한다      |
| 4. 데이터 저장 | 샘플링된 데이터와 비교 데이터를 각각 별도 파일로 저장한다                       |

### 데이터 정제(필터링, 클리닝, 정규화) (data-preprocessing.py)
| 단계 | 설명                                                                  |
|:----|:--------------------------------------------------------------------|
| **CSV 데이터 읽기** | `spam_emails_data.csv` 파일을 읽어 데이터를 불러온다.                                |
| **레이블 필터링(정규화)** | 'label' 컬럼 값이 'Ham' 또는 'Spam'인 행만 추출한 후, `0(HAM)-1(SPAM)`으로 정규화한다.  |
| **텍스트 길이 필터링** | ‘text’ 컬럼의 길이가 1024자를 초과하는 경우는 제외하여, 지나치게 긴 텍스트는 분석 대상에서 제거한다.      |
| **언어 필터링** | langdetect 라이브러리를 사용해 각 텍스트의 언어를 판별하고, 영어로 작성된 텍스트만 남긴다.            |
| **중복된 행 제거** | 동일한 값으로 구성된 중복 행을 제거하여 데이터의 품질을 향상시킨다.                              |
| **결과 저장** | 최종적으로 필터링된 데이터를 `spam_emails_data_filtered.csv`라는 이름의 새로운 파일로 저장한다. |

## 모델 학습 (MobileBERT-Finetune-GPU.py)

## 토큰화
### 토큰화 과정
| 구분            | 설명                                                                 |
|---------------|----------------------------------------------------------------------|
| **단어 토큰화**    | 각 이메일 텍스트를 단어 단위로 나누어 분석하는 과정이다              |
| **BERT 토큰화**  | MobileBERT 모델을 위한 토큰화 기법을 적용하여, 텍스트를 BERT에서 이해할 수 있는 형식으로 변환한다 |
| **Tokenizer** | BERT 토큰화를 수행하는 도구로, 문장을 토큰 ID 시퀀스로 변환한다         |

### MobileBERT 모델 설정
| 항목               | 내용                                                                 |
|--------------------|----------------------------------------------------------------------|
| **모델 아키텍처**     | MobileBERT는 BERT를 경량화하여 설계된 모델로, 경량화에도 불구하고 빠른 속도와 우수한 성능을 유지한다.          |
| **학습 데이터**       | 학습 데이터로는 샘플링된 spam_emails_sampled_filter.csv 파일을 사용하였다.         |
| **학습 클래스의 수**  | 라벨은 총 2개로, `0(정상)`과 `1(스팸)`으로 구성되어 있다.                                           |

### 학습 파라미터
| 항목               | 값 및 설명                                                             |
|--------------------|------------------------------------------------------------------------|
| **배치 크기**        | 8                                                                     |
| **학습률**          | 2e-5                                                                  |
| **에포크 수**        | 4 (한 에포크당 학습 데이터 3,800건, 검증 데이터 950건)                   |
| **최적화 알고리즘**   | Adam Optimizer 사용                                                   |

## 학습 데이터의 수에 따른 모델 평가

> ![picture_01](picture/accuracy.png)<br>
**평가 지표**: 모델의 예측 성능은 **accuracy와, loss**를 기준으로 평가하며, 이를 통해 모델의 전반적인 성능을 확인하고자 한다.<br><br>
제공된 그래프를 보면, 학습 데이터가 4,750건일 떄 정확도는 약 96% 수준까지 도달한 것을 확인할 수 있다.<br><br>
학습 데이터 수가 많으면 많을수록 모델 학습/검증 성능은 전반적으로 향상되지만, 그 증가폭이 급격하지는 않은 것으로 나타난다.

## 모델 테스트 결과 (MobileBERT-inference.py)
> ![picture_02](picture/inference.png)<br>
비교 데이터 64,101건을 대상으로 학습 데이터의 수에 따라 정확도를 비교한 결과, 정확도는 대체로 96%에서 98% 사이로 나타났다.
> 
### 모델 개선 방법
- 하이퍼파라미터 튜닝: 학습률, 배치 크기 등 주요 하이퍼파라미터를 조정하여 모델 성능을 최적화할 수 있다.
- 데이터 증강: 정상 및 스팸 관련 데이터를 인위적으로 확장하여 학습 데이터의 다양성과 양을 보완할 수 있다.

## 학습 결론
학습 데이터가 약 4,750건일 때 정확도가 약 96%까지 도달했고, 전체 테스트 데이터(64,101건)에서의 추론 결과도 대체로 96%에서 98% 사이로 나타났다.
데이터 양이 늘어날수록 정확도는 꾸준히 좋아졌지만, 일정 수준 이상부터는 급격한 향상보다는 완만한 개선에 그쳤다. 이 결과는 MobileBERT가 비교적 적은 양의 데이터만으로도 꽤 안정적인 성능을 보여준다는 걸 의미한다.

앞으로 성능을 더 높이기 위해서는 하이퍼파라미터를 조정해 보거나, 스팸 및 정상 데이터에 대한 데이터 증강을 시도해볼 수 있다. 이런 방법들을 적용하면 모델의 정밀도와 실제 적용 가능성을 좀 더 끌어올릴 수 있을 것으로 보인다.

## 데이터 시각화를 위한 모델 예측 데이터 준비

LDA 시각화를 위한 데이터 준비를 위해, 학습된 모델로 비교 데이터의 텍스트(라벨 제외)에 대해 예측을 수행하였다.
이 중 스팸으로 분류된 텍스트를 대상으로, 어떤 주제(토픽)로 군집되는지를 분석하고자 한다.

### 처리 순서
| 단계 | 설명                                                                                   |
|------|--------------------------------------------------------------------------------------|
| 1 | `MobileBERT-sample-export.py` 스크립트를 실행한다.                                            |
| 2 | 비교 데이터 64,107건 중에서, 모델이 ‘스팸’으로 예측한 데이터만을 추출한다.                                       |
| 3 | 모델이 예측한 결과를 바탕으로 스팸으로 분류된 데이터는 총 30,937건이다. (예측 기반 추출이므로 실제 라벨 분포와는 다소 차이가 있을 수 있다.) |
| 4 | 해당 결과는 `spam_emails_model_predict.csv` 파일로 저장하였다.                                    |

## 데이터 시각화(data-topicModeling.py)

### 전체적인 데이터 시각화 과정

| 순서 | 단계 설명                  | 주요 내용 및 사용 라이브러리                                       |
|:--:|------------------------|-------------------------------------------------------------------|
| 1  | 라이브러리 불러오기 및 NLTK 다운로드 | `pandas`, `nltk`, `gensim`, `pyLDAvis` 라이브러리를 사용한다.               |
| 2  | 데이터 불러오기               | `spam_emails_data_filtered.csv` 파일에서 텍스트 데이터를 불러온다.           |
| 3  | 사용자 정의 불용어 추가 설정       | 기본 영어 불용어 외에 `escapenumber`, `escapelong` 등 사용자 정의 불용어도 제거한다. |
| 4  | 전처리 함수 정의              | 소문자 변환, 특수문자 제거, 토큰화, 불용어 제거, 2글자 이하 단어 제거 등을 포함한다. |
| 5  | 전처리 적용                 | 정의한 전처리 함수를 원본 텍스트에 적용하여, 전처리된 결과를 clean_text 컬럼에 저장한다. |
| 6  | LDA 모델 학습 함수 정의        | `Gensim`의 `LdaModel`을 사용해 토픽 모델을 학습할 수 있도록 함수로 정의한다.       |
| 7  | LDA 모델 학습 및 토픽 출력      | 학습된 모델로부터 총 6개의 주요 토픽을 추출한다.                         |
| 8  | LDA 결과 시각화 및 저장        | `pyLDAvis`를 활용하여 결과를 시각화하고, HTML 파일(`spam_topics.html`)로 저장한다. |

### 스팸 메일로 분류된 데이터 분석 (spam_topics.html)
> ![spam_picture](picture/spam-lda.png)

학습된 모델을 기반으로한 예측 데이터를 가지고 LDA 기반 토픽 모델링을 수행하였다. 그 결과를 바탕으로 대표적인 예제 6건을 추출하였으며, 이를 통해 주요 주제를 확인할 수 있었다. 또한 각 토픽은 스팸 메일의 전형적인 특성을 잘 드러내고 있음을 확인할 수 있다.

| 토픽 번호 | 주요 키워드                                                                                                          | 분류         | 해석                                                                 |
|-----------|--------------------------------------------------------------------------------------------------------------------|--------------|----------------------------------------------------------------------|
| **Topic 1** | `please`, `com`, `enron`, `sent`, `subject`, `message`, `thanks`, `know`, `original`, `email`                       | 스팸(기타)     | 일반적인 이메일 회신이나 포워딩 형태를 모방한 대화형 스팸으로 해석된다.                                |
| **Topic 2** | `see`, `may`, `web`, `http`, `please`, `click`, `canadianpharmacy`, `try`, `low`, `speakup`                        | 스팸(의약품)   | 온라인 약국, 특히 불법 의약품(예: 캐나다약국)을 홍보하는 형태의 스팸으로 해석된다.                         |
| **Topic 3** | `help`, `posting`, `please`, `guide`, `http`, `html`, `ethz`, `stat`, `list`, `day`                                 | 스팸(기타)     | 가이드, 포럼, 기술 문서 형식을 가장한 스팸 콘텐츠로 해석된다.                                             |
| **Topic 4** | `org`, `perl`, `http`, `message`, `original`, `subject`, `sent`, `mail`, `unsubscribe`, `com`                      | 스팸(기타)     | 오픈소스 커뮤니티나 기술 메일링 리스트를 사칭한 형태의 자동화된 스팸으로 보인다.                          |
| **Topic 5** | `one`, `get`, `time`, `like`, `http`, `com`, `day`, `would`, `many`, `site`                                         | 스팸(기타)     | 막연한 표현과 일반적인 단어로 구성된, 관심 유도형 혹은 랜딩 페이지 유입 유도 스팸으로 해석된다.              |
| **Topic 6** | `http`, `com`, `www`, `net`, `get`, `viagra`, `save`, `online`, `best`, `cialis`                                   | 스팸(의약품)   | 비아그라, 시알리스 등 불법 의약품 관련 키워드를 포함한 명확한 의약품 광고형 스팸이다.                     |

## 최종 결론

스팸으로 분류된 이메일 데이터를 대상으로 LDA 토픽 모델링을 수행한 결과, 학습된 분류 모델이 스팸 메일의 주요 특성과 주제를 효과적으로 반영하고 있음을 확인할 수 있었다.
무작위로 추출한 6개의 토픽은 의약품 광고, 이메일 회신·포워딩 사칭, 기술 문서 위장, 랜딩 페이지 유도형 등 스팸 메일에서 자주 나타나는 전형적인 패턴을 잘 드러냈다. 각 토픽은 핵심 키워드를 중심으로 스팸의 유형을 명확히 구분할 수 있었으며, 이는 분류 모델이 실제 스팸 메일의 주제적 특성을 정확히 학습했음을 시사한다.
결과적으로, 본 프로젝트에서 학습된 모델은 스팸 탐지뿐만 아니라 스팸 내의 다양한 주제 분류까지도 안정적으로 수행할 수 있는 수준의 성능을 보였으며, 향후 스팸 유형에 따른 대응 전략 수립에도 유용하게 활용될 수 있을 것으로 판단된다.
