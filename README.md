# MobileBERT를 이용한 문장 데이터 분석

---
## 프로젝트 목표
이 프로젝트는 **MobileBERT** 모델을 사용하여 `스팸 이메일을 분류하는 시스템을 구현`하는 것입니다. 또한 이메일 텍스트 데이터를 입력받아 해당 이메일이 **스팸인지 정상인지**를 `정확하게 예측하는 모델을 만드는것을 목표`로 합니다:

---

## Dataset 설명
- **kaggle에 있는 문장 분류를 위한 메일 Ham/Spam Dataset**을 이용 
- 이메일 문장인 `text` 와 `label`로 구성되어 있음.
- 행은 총 **193,849개**의 데이터를 가지고 있음.
- csv 파일로 저장되어 있기 때문에 `특정 이메일 문장이 너무 길어 엑셀이나 pandas로 열었을때 문자 깨짐` 발생
(데이터 전처리 필요)

---

## 데이터 전처리 
1. **필터링**: 데이터를 로드하고, `label` 값에 따라 데이터를 분리합니다.
2. **데이터 클리닝 및 정규화**: 이메일 텍스트에서 텍스트의 길이와 언어를 필터링하고 `label`에 대해서 **0과 1**로 정규화 시킵니다.
3. **샘플링**: 각 `label`에 대해 13,000개의 샘플을 무작위로 선택합니다.
4. **데이터 합치기**: 샘플링된 데이터와 나머지 데이터를 각각 별도의 파일로 저장합니다.

### 1~2. 데이터 정제(필터링, 클리닝, 정규화)
- **CSV 데이터 읽기**: `spam_emails_data.csv` 파일을 읽어 들입니다.
- **레이블 필터링(정규화)**: 'label' 컬럼 값이 'Ham' 또는 'Spam'인 행만 필터링하여 `0(HAM)-1(SPAM)`으로 정규화 하여 사용합니다.
- **텍스트 길이 필터링**: 'text' 컬럼의 길이가 1024자 이하인 행만 필터링하여, `너무 긴 텍스트 데이터를 제외`합니다.
- **언어 필터링**: 텍스트가 영어로 작성된 경우만 필터링하기 위해, `langdetect` 라이브러리를 사용하여 언어가 `영어인 텍스트만` 남깁니다.
- **결과 저장**: 필터링된 데이터를 `spam_emails_data-filter.csv`라는 새로운 파일로 저장합니다.

### 3~4. 데이터 샘플링 후 저장
- **CSV 데이터 읽기**: 위에 생성했던 `spam_emails_data-filter.csv` 파일을 읽어 들입니다.
- **데이터 샘플링**: `label` 값에 따라 13,000개의 샘플을 각각 추출하여 균형 잡힌 데이터를 만듭니다.
- **샘플링된 데이터와 나머지 데이터 분리**: - **샘플링된 데이터와 나머지 데이터 분리**: `scikit-learn`의 `train_test_split` 함수를 사용하여 데이터를 무작위로 분리한 후, 샘플링된 데이터와 나머지 데이터를 두 개의 CSV 파일로 저장합니다.
  - `spam_emails_sampled_filter.csv`: 샘플링된 데이터
  - `spam_emails_remaining_filter.csv`: 나머지 데이터

## 토큰화

### 토큰화 과정
- **단어 토큰화**: 각 이메일 텍스트를 단어 단위로 나누어 분석합니다.
- **BERT 토큰화**: MobileBERT 모델을 위한 토큰화 기법을 적용하여, 텍스트를 BERT에서 이해할 수 있는 형식으로 변환합니다.
  - **Tokenizer** 사용
---

## 모델 학습

### MobileBERT 모델 설정
- **모델 아키텍처**: MobileBERT는 BERT의 경량화된 버전으로, 빠르고 효율적인 성능을 제공합니다.
- **학습 데이터**:` 전처리된 이메일 텍스트`와 `정규화 된 label`값 **HAM(0), SPAM(1)** 을 학습 데이터로 사용합니다.

### 학습 파라미터
- **배치 크기**: 48
- **학습률**: 2e-5
- **에포크 수**: 4
- **최적화 알고리즘**: Adam Optimizer 사용

### 모델 평가
- **평가 지표**: tensorboard 를 활용해 모델의 예측 성능을 확인하고 **accuracy와, loss**를 통해 모델의 전반적인 성능을 평가합니다.
- **교차 검증**: 데이터를 `(학습용,검증용), (테스트용)`으로 나누어 교차 검증을 실시합니다.

### 모델 저장
- 학습된 모델의 가중치를 **mobilebert_custom_model.pt** 폴더에 저장하여, 다양한 환경에서 사용할 수 있도록 합니다.
